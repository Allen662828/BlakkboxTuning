# Blakkbox Workflow Documentation

This folder contains the Blakkbox workflow documents used for Denso Diesel MOD review, checksum correction, and delta-rule handling.

## Files

- `blakkbox-universal-denso-diesel-master-workflow.pdf` - Universal Denso Diesel master workflow reference.
- `blakkbox-complete-hybrid-pipeline.pdf` - Complete hybrid pipeline workflow reference.
- `delta-workflow-rules.md` - Delta workflow rules for comparing ORIGINAL, MOD, and fixed outputs.

## Placement

These are documentation assets and should live under `docs/workflows/blakkbox/`.

Do not place PDFs or Markdown documentation inside `.github/workflows/`; that folder is only for GitHub Actions `.yml` automation files.
