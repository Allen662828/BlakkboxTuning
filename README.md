# DENSO ROM STUDIO AUTO

Offline DENSO ROM Analysis Platform

Features:

* BIN comparison
* ROM region classification
* Map candidate detection
* Delta analysis
* OEM validation
* JSON export
* CSV export
* HTML reporting

Supported Platforms:

* Toyota DENSO
* Mitsubishi DENSO
* Nissan DENSO

Supported ROM Sizes:

* 368KB
* 512KB
* 768KB
* 1MB
* 2MB
* 4MB

Project Status:

* Development
* Offline Analysis Platform
* Research and Educational Use
